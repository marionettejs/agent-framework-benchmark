# Redistribution and privacy boundaries

The owner authorized publication of the generated app code and these benchmark results. This snapshot adds no blanket license to the inherited harness/fixture or third-party packages. No root license grant for all upstream material was established in the inspected base. Existing notices are retained; consult the relevant owners and package licenses before reuse. Dependency implementations are not vendored. The lockfiles retain public registry identity/integrity; source-only normalization uses pinned dependencies installed separately by the reader.

Pokémon data files, sprites, cries, reference artwork, app screenshots, Lighthouse image payloads, dependency trees and build products are not added. Image references in generated source and network metadata do not embed those assets. The supplied fixture stylesheet is restored by reference to the already-inherited template file and its hash, rather than redistributed in every app. Some generated style rules incorporate supplied design tokens; comprehensive ownership clearance for every fragment has not been independently established.

Raw generation transcripts, hidden reasoning, account identities, authentication/session files, credential values, private execution routing and host paths are not distributed. Native timing/usage files preserve selected nonsecret numeric fields and timestamps from complete receipts; measurement JSON retains all numeric samples and detailed diagnostics where available, with image payloads and private identifiers/paths removed. Test logs are curated primary passing logs. Publication-copy dependency routing translations are disclosed in `publication-adaptations.json` and per-app source manifests; app implementation source is otherwise byte-identical to its selected source.

Review covered the selected filenames/text/JSON, explicit secret/identity patterns, source and formatter hashes, current data scope and reachable Git text history. It is not an exhaustive secret detector, full legal clearance, dependency security audit or guarantee about every inherited object. No provider credentials are needed for static data verification. No app, benchmark or model was executed for publication.
